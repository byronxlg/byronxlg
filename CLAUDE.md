# byronxlg

GitHub profile README for https://github.com/byronxlg. `main` is what the profile shows. The
projects section of `README.md` and the SVGs in `assets/cards/` are generated by
`scripts/update_projects.py`, run daily by `.github/workflows/update-projects.yml`; do not edit
the generated block by hand.

Operational docs live in `runbook/`:

- [runbook/README.md](runbook/README.md): what this is, what "live" means, schedules.
- [runbook/updates.md](runbook/updates.md): how the README is generated, running it by hand,
  rollback, risky changes.
